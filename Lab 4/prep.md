## 3. Part A：电容触摸

1. 关闭电源后连接 MPR121 与 Qwiic 线，核对板子型号和连接方向。
2. 用鳄鱼夹或铜箔把一个导电物体接到触摸通道；记录实际通道号。
3. 通电，激活 Lab 4 环境，运行 `python cap_test.py`。
4. 分别观察未触摸、触摸、松开的输出；按 Ctrl+C 停止。
5. 保存接线照片和终端输出，记录误触、物体接触和导线摆放造成的变化。

脚本保留了课程的 `Twizzler` 输出名称；你的报告应写实际使用的物体，不能据此声称用了 Twizzlers。

## 4. Part B：逐个探索输入

每次先确认所连接的板子，再运行对应脚本；更换接线前关闭电源。

| 输入 | 课程脚本 | 观察内容 |
| --- | --- | --- |
| APDS-9960 接近 | `proximity_test.py` | 手靠近与远离的数值变化 |
| APDS-9960 手势 | `gesture_test.py` | 上下左右方向识别和安装方向 |
| APDS-9960 光与颜色 | `color_test.py` | 遮挡、光照、不同颜色物体的读数 |
| 旋转编码器 | `encoder_test.py` | 顺逆时针位置变化与按下/松开 |
| 摇杆 | `joystick_test.py` | X、Y 与按钮值 |
| 课程距离/接近板 | README 中对应的 `qwiic_distance.py` 或 `distance_test.py` | 空场景与物体放置后的数值差别 |

距离板有不同例子，按实物型号选脚本。先分别验证单个输入，再考虑串接多个设备。

## 5. Part C：舵机

1. 核对 Servo pHAT 叠放方向与通道 0 的舵机插头方向。
2. Pi 使用自身电源；Servo pHAT 使用独立 USB-C 供电。课程明确要求不从 Pi 的 5V 引脚给舵机供电。
3. 第一次试转不装纸板机构或负载，留出活动空间。
4. 激活 Lab 4 环境，运行已验证的有限时小范围脚本 `python servo_center_test.py --channel 1`。课程 `pi_servo_hat_test.py` 是持续运行的示例，使用不同范围映射，不能不加核对地代替本次小范围测试。
5. 记录实际舵机型号、可用范围、抖动与接线照片；课程脚本的 0–120° 是示例设置，需结合实物确认。
